Mountain route planner
======================

Code lives on [Github](https://github.com/Campano/gpx-route-planner)
App lives on [gpx.cat](https://gpx.cat)

Run locally
------------

```shell
git clone https://github.com/Campano/gpx-route-planner
cd gpx-route-planner
npm run dev
```

Deploy to prod
--------------

```shell
npm run deploy
```
